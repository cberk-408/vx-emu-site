# VX EMU — Premium Valorant Emulator

Premium Valorant emülatörü için geliştirilmiş modern web sitesi.

## Özellikler

- Responsive tasarım (mobil uyumlu)
-暗 tema ve neon vurguları
- Animasyonlu geçişler
- SSS (Sıkça Sorulan Sorular) accordions
- Kullanıcı değerlendirmeleri
- Premium fiyatlandırma kartları

## Kurulum

```bash
git clone https://github.com/KEREM200608/vx-emu-site.git
cd vx-emu-site
```

Dosyaları sunucunuza yükleyin veya doğrudan tarayıcıda açın.

## Teknolojiler

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
- Font Awesome 6
- Google Fonts (Inter, JetBrains Mono)
